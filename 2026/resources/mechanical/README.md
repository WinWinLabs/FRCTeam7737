# Mechanical Resources — 2026

This folder stores all mechanical engineering documents for the 2026 robot.

## File Organization

```
mechanical/
├── cad/              # CAD source files (.f3d, .step, .sldprt) and exports (.pdf, .dxf)
├── drawings/         # Dimensioned engineering drawings (PDF)
├── bom/              # Bill of Materials spreadsheets
└── photos/           # Build progress and reference photos
```

## Naming Convention

Use descriptive names with dates:
- `drivetrain-v1-2026-01-15.pdf`
- `shooter-assembly-v3.step`
- `bom-2026-week3.xlsx`
